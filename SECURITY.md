# Güvenlik Politikası

## Desteklenen Versiyonlar

| Versiyon | Destek              |
| -------- | ------------------- |
| 0.1.x    | ✅ Aktif geliştirme |

## Açık Bildirimi

Lütfen güvenlik açıklarını **public issue** olarak açmayın. Bunun yerine:

📧 **E-posta:** security@galatabaker.app (henüz kurulmadı, kurulana kadar GitHub Security Advisories kullanın)

🔒 **GitHub Security Advisories:** https://github.com/galatabaker/galatabaker/security/advisories/new

## Yanıt Süresi

- 48 saat içinde ilk yanıt
- 7 gün içinde değerlendirme
- 30 gün içinde fix (kritik ise daha hızlı)

## Teşvik

Şu an bir bug bounty programı yok. Düzgün disclosure yapan araştırmacılar GitHub'ta kredilendirilir.

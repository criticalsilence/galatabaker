# Katkıda Bulunma

Şu an proje solo geliştiricili. Dış katkılar için ileride CONTRIBUTING rehberi detaylandırılacak.

## Davranış Kuralları

Uygar, yapıcı ve kapsayıcı ol. CODE_OF_CONDUCT.md ileride eklenecek.

## Commit Mesajları

[Conventional Commits](https://www.conventionalcommits.org/) kullanıyoruz:

```
feat(scope): yeni özellik
fix(scope): bug fix
chore(scope): tooling/CI
docs(scope): döküman
test(scope): test
refactor(scope): refactor
```

## PR Süreci

1. Branch: `feat/kısa-açıklama` veya `fix/kısa-açıklama`
2. PR template'i doldur
3. CI yeşil olmalı
4. Solo geliştirici — review opsiyonel
